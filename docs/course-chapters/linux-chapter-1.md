### Linux 是什么

Linux 是一种开源的、类 Unix 的操作系统。严格来说，"Linux"一词最初只指代操作系统内核（Kernel），内核是系统的核心，负责管理硬件资源、进程调度、内存分配等底层工作。日常所说的"Linux 系统"通常是指基于 Linux 内核的完整操作系统。

```bash
# 查看当前系统的内核版本
uname -r
# 输出示例：5.15.0-76-generic
```

### 内核与发行版的区别

内核本身无法直接使用，还需要配合各种工具软件、图形界面、包管理器等才能构成一个可用的操作系统。在内核基础上打包了各类软件的完整系统称为"发行版"（Distribution）。

```bash
# 查看当前系统的发行版信息
cat /etc/os-release
# 输出示例包含 NAME="Ubuntu" VERSION="22.04 LTS" 等字段
```

### 发展历史

Linux 的发展经历了几 个关键节点：

- **1969 年**：Ken Thompson 和 Dennis Ritchie 在贝尔实验室创建 Unix 操作系统，奠定了类 Unix 系统的基础。
- **1983 年**：Richard Stallman 发起 GNU 计划，目标是创建一套完全自由的类 Unix 操作系统，GNU 工具链（如 gcc、bash）后来成为 Linux 生态的重要组成部分。
- **1991 年**：Linus Torvalds 在赫尔辛基大学创建了 Linux 内核的最初版本并在网上发布。
- **1994 年**：Linux 内核 1.0 版本正式发布，标志着 Linux 走向成熟。

### 主流发行版

Linux 发行版众多，按包管理和体系可大致分为三大系列：

| 系列 | 代表发行版 | 包管理器 |
|------|-----------|---------|
| Debian 系 | Ubuntu、Linux Mint | apt / dpkg |
| Red Hat 系 | RHEL、CentOS、Rocky Linux | yum / dnf / rpm |
| Arch 系 | Arch Linux、Manjaro | pacman |

```bash
# 不同发行版查看版本信息的方式略有差异
# Debian/Ubuntu 系
lsb_release -a

# Red Hat 系
cat /etc/redhat-release
```

### 命令提示符

登录 Linux 命令行后，会看到一行提示符，例如 `student@ubuntu:~$`。各部分含义如下：

- `student`：当前登录的用户名
- `@`：分隔符
- `ubuntu`：主机名
- `:`：分隔符
- `~`：当前所在目录（`~` 表示家目录）
- `$`：普通用户提示符；`#` 表示 root 用户（超级管理员）

```bash
# 普通用户提示符
student@ubuntu:~$

# root 用户提示符
root@ubuntu:~#
```

### 命令通用语法结构

Linux 命令的基本语法结构为：

```
命令名 [选项] [参数]
```

- **命令名**：要执行的程序名称，如 `ls`、`cd`。
- **选项**：以 `-` 开头，用于修改命令的行为。多个单字母选项可合并，如 `ls -l -a` 等价于 `ls -la`。
- **参数**：命令操作的对象，如文件名、目录路径。

```bash
# 命令名 + 选项 + 参数
ls -l /home

# 合并多个单字母选项
ls -la /home
```

### pwd 命令

`pwd` 是 Print Working Directory 的缩写，用于打印当前工作目录的绝对路径。这是一个无参数命令，直接输入即可。

```bash
# 打印当前工作目录
pwd
# 输出示例：/home/student
```

### cd 命令

`cd` 是 Change Directory 的缩写，用于切换当前工作目录。`cd` 支持多种特殊符号：

| 符号 | 含义 |
|------|------|
| `~` | 当前用户的家目录 |
| `.` | 当前目录 |
| `..` | 上一级目录 |
| `-` | 上一次所在的目录 |
| `/` | 根目录 |

```bash
# 切换到家目录
cd ~

# 切换到上一级目录
cd ..

# 切换到上一次所在的目录
cd -

# 使用绝对路径切换
cd /etc
```

### ls 命令

`ls` 是 List 的缩写，用于列出目录内容。常用选项如下：

| 选项 | 功能 |
|------|------|
| `-l` | 以长格式显示详细信息 |
| `-a` | 显示所有文件，包括以 `.` 开头的隐藏文件 |
| `-h` | 以人类可读格式显示文件大小（如 K、M） |
| `-t` | 按修改时间排序 |
| `-r` | 反向排序 |
| `-R` | 递归列出子目录内容 |
| `-d` | 仅显示目录本身，不显示其内容 |

```bash
# 长格式列出当前目录内容
ls -l

# 显示所有文件（含隐藏文件）
ls -a

# 以人类可读大小、长格式显示
ls -lh /home
```

`ls -l` 输出的每一行包含多个字段，以 `-rw-r--r-- 1 student student 2048 Aug 5 10:00 report.txt` 为例：

| 字段 | 含义 |
|------|------|
| `-rw-r--r--` | 文件类型与权限（第1位为类型，后9位为权限） |
| `1` | 硬链接数 |
| `student` | 所有者 |
| `student` | 所属组 |
| `2048` | 文件大小（字节） |
| `Aug 5 10:00` | 最后修改时间 |
| `report.txt` | 文件名 |

### 帮助体系

Linux 提供了多种获取命令帮助的方式：

- **man 手册**：`man 命令名`，打开完整的使用手册，按 `q` 退出。
- **--help 选项**：`命令名 --help`，在终端直接显示简要帮助信息。
- **info**：`info 命令名`，显示更详细的 info 文档。

```bash
# 查看 ls 命令的详细手册
man ls

# 查看 ls 的简要帮助
ls --help
```

### Tab 自动补全与历史命令

命令行提供多种快捷操作提升效率：

- **Tab 键**：自动补全命令名、文件名和目录名。按一次 Tab 自动补全，有多个匹配时按两次 Tab 显示所有候选。
- **上下方向键**：浏览历史命令。
- **history 命令**：列出历史命令记录。
- `!!`：重复执行上一条命令。

```bash
# 查看历史命令
history

# 重复执行上一条命令
!!
```

[示例 title="基本命令综合演示"]

```bash
# 查看当前所在目录
pwd

# 切换到家目录
cd ~

# 列出当前目录所有文件（含隐藏文件）
ls -la

# 创建一个测试目录并进入
mkdir test_dir
cd test_dir

# 返回上一次所在的目录
cd -

# 查看 cd 命令的手册
man cd
```

[提示 title="命令区分大小写"]

Linux 命令严格区分大小写。`LS` 和 `ls` 是不同的，`LS` 会被系统认为是一个不存在的命令。文件名同样区分大小写，`Report.txt` 和 `report.txt` 是两个不同的文件。

[提示 title="善用 Tab 补全"]

输入命令或路径的前几个字符后按 Tab 键可以自动补全，既能提高输入速度，也能避免拼写错误。当补全不唯一时，连按两次 Tab 会列出所有匹配项供选择。

[警告 title="root 提示符 # 与普通用户提示符 $"]

提示符为 `#` 时表示当前是 root 用户，拥有系统最高权限，执行的任何命令都可能影响整个系统。在日常操作中应尽量使用普通用户，仅在需要时通过 sudo 临时提权，避免误操作造成系统损坏。

解析：`-l` 以长格式显示详细信息，`-h`（human-readable）将文件大小以 K、M、G 等人类易读的单位显示，而非默认的字节数。合并写为 `-lh`。这两个选项组合在日常查看文件时非常常用。

是否用于 Battle：是

Battle 展示类型：code
