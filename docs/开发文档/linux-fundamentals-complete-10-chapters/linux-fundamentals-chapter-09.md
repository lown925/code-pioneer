# 第九章：Shell 基础与脚本

章节简介：本章围绕“Shell 基础与脚本”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 掌握赋值与双引号变量引用
- 使用 $(...) 捕获命令标准输出
- 理解 if 根据命令退出状态分支
- 对明确列表重复执行逻辑
- 封装重复逻辑并使用位置参数
- 理解 set -euo pipefail 与显式校验
