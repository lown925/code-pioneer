# Linux 基础与常用命令

课程定位：面向数据科学与大数据技术、计算机科学与技术、软件工程等专业方向的 Linux 基础课程。课程从终端与文件系统出发，逐步覆盖文件操作、文本处理、权限、进程、软件包与服务、网络、Shell 脚本和综合运维实践。

建议前置：Python 基础入门或具备基本程序设计概念。

教学方法：为什么 → 怎么做 → 命令/代码 → 分析 → 应用。

课程章节：
- 第1章：Linux 与终端入门
- 第2章：文件系统与目录导航
- 第3章：文件与目录操作
- 第4章：文本查看、搜索与处理
- 第5章：用户、用户组与权限
- 第6章：进程与任务管理
- 第7章：软件包与系统服务
- 第8章：Linux 网络基础与常用命令
- 第9章：Shell 基础与脚本
- 第10章：Linux 综合运维实践

统一题库结构：
- 每章 6 课时 / 18 题
- 每课时 1 道 EASY 非 Battle、1 道 MEDIUM Battle、1 道 HARD Battle
- 每章 3 道 CODE_FILL（均为 HARD Battle）
- 每章共 12 道 Battle：6 MEDIUM + 6 HARD
- Battle 仅使用 SINGLE_CHOICE / CODE_FILL
- CODE_FILL 包含可见 `____`、非空可接受答案、标准完整代码
