# 第十章：Linux 综合运维实践

章节简介：本章围绕“Linux 综合运维实践”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 区分 df 和 du
- 组合 tail、grep、wc
- 组合 systemctl、ss、curl 分层验证
- 复制备份并验证内容
- 在变更前确认版本、配置、磁盘、权限、端口
- 形成统一的故障处理方法论

## 课时 1：磁盘与目录空间观察

课时简介：区分 df 和 du。

预计学习时间：20 分钟

### 正文

[标题]
为什么要学：磁盘与目录空间观察

[文本]
区分 df 和 du是后续 Linux 操作和排查的重要基础。真实环境中，命令往往与路径、权限、进程状态或系统配置共同作用，因此不能只背命令名称，还要理解它解决的问题、输入条件和风险边界。

[标题]
怎么做

[文本]
df 看文件系统容量，du 看指定路径内容占用。学习时应先观察命令作用对象，再确认参数和当前环境；涉及写入、删除、权限、服务或网络配置时，先做只读检查，再执行最小必要操作。

[代码 language=bash]

[/代码]

[文本]
上面的示例用于演示“磁盘与目录空间观察”的核心语义。阅读时重点关注命令的输入、选项、参数和输出，而不是只记住最终结果。
