# 第三章：文件与目录操作

章节简介：本章围绕“文件与目录操作”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 创建文件和目录，理解 mkdir -p
- 理解 cp 的源和目标
- 理解 mv 可移动也可改名
- 掌握删除文件与递归删除的风险
- 理解 * 与 ? 的基本文件名展开
- 组合 mkdir、cp、mv、ls 完成文件整理

## 课时 1：touch 与 mkdir

课时简介：创建文件和目录，理解 mkdir -p。

预计学习时间：20 分钟

### 正文

[标题]
为什么要学：touch 与 mkdir

[文本]
创建文件和目录，理解 mkdir -p是后续 Linux 操作和排查的重要基础。真实环境中，命令往往与路径、权限、进程状态或系统配置共同作用，因此不能只背命令名称，还要理解它解决的问题、输入条件和风险边界。

[标题]
怎么做

[文本]
touch 可创建空文件，mkdir -p 可连同父目录创建。学习时应先观察命令作用对象，再确认参数和当前环境；涉及写入、删除、权限、服务或网络配置时，先做只读检查，再执行最小必要操作。

[代码 language=bash]

rm -rf "$base"; mkdir -p "$base/logs"; touch "$base/logs/app.log"; ls "$base/logs"; rm -rf "$base"
[/代码]

[文本]
上面的示例用于演示“touch 与 mkdir”的核心语义。阅读时重点关注命令的输入、选项、参数和输出，而不是只记住最终结果。

### 正文

[标题]
为什么要学：文件整理综合练习

[文本]
组合 mkdir、cp、mv、ls 完成文件整理是后续 Linux 操作和排查的重要基础。真实环境中，命令往往与路径、权限、进程状态或系统配置共同作用，因此不能只背命令名称，还要理解它解决的问题、输入条件和风险边界。

[标题]
怎么做

[文本]
综合操作应明确每一步源、目标和验证结果。学习时应先观察命令作用对象，再确认参数和当前环境；涉及写入、删除、权限、服务或网络配置时，先做只读检查，再执行最小必要操作。

[代码 language=bash]
base=/tmp/linux_files_demo
rm -rf "$base"; mkdir -p "$base/inbox" "$base/archive"; printf '%s\n' report > "$base/inbox/report.txt"; cp "$base/inbox/report.txt" "$base/archive/report.bak"; mv "$base/inbox/report.txt" "$base/inbox/final.txt"; ls "$base/inbox" "$base/archive"; rm -rf "$base"
[/代码]

[文本]
上面的示例用于演示“文件整理综合练习”的核心语义。阅读时重点关注命令的输入、选项、参数和输出，而不是只记住最终结果。
