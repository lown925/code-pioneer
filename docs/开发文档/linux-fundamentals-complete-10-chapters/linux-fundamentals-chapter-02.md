# 第二章：文件系统与目录导航

章节简介：本章围绕“文件系统与目录导航”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 认识 /、/home、/etc、/var、/tmp 等常见目录
- 理解当前工作目录和相对路径的起点
- 使用 ls、-a、-l 查看目录
- 掌握 cd、~、..
- 区分以 / 开头的绝对路径和相对路径
- 用双引号保护路径变量并验证位置
