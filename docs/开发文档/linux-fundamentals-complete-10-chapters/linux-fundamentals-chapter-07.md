# 第七章：软件包与系统服务

章节简介：本章围绕“软件包与系统服务”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 理解 APT、DNF 与发行版生态
- 区分 apt update 与 apt install
- 认识 dnf install/remove
- 理解服务状态与 systemctl
- 区分当前运行状态的不同操作
- 区分开机启用与当前 active

---
