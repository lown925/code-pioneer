# 第一章：Linux 与终端入门

章节简介：本章围绕“Linux 与终端入门”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 区分 Linux 内核、发行版与 Shell 的角色
- 理解命令名、选项和参数的基本结构
- 理解短/长选项以及单引号、双引号差异
- 会使用 type、--help 和 man 查资料
- 理解 stdin/stdout/stderr 三条标准流
- 理解 $?、&& 与 ||

---
