# 第五章：用户、用户组与权限

章节简介：本章围绕“用户、用户组与权限”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 认识 whoami、id、UID、GID
- 读懂 owner/group/others 的 rwx
- 用 u/g/o 与 +/- 修改权限
- 理解 r=4、w=2、x=1
- 理解 owner/group 与 chown 语义
- 理解 sudo 只应用于确实需要提升权限的操作

---
