# 第八章：Linux 网络基础与常用命令

章节简介：本章围绕“Linux 网络基础与常用命令”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 认识 ip addr/ip link
- 理解 ICMP 连通性与局限
- 区分域名解析与直接 IP 连接
- 查看 TCP 监听 socket
- 使用 curl 检查 HTTP 层
- 按 DNS、地址/端口、应用层逐级排查

---
