# 第六章：进程与任务管理

章节简介：本章围绕“进程与任务管理”建立从概念到命令、从命令到排查方法的系统认识。课程强调先理解为什么，再学习怎么做，并通过可验证的 Bash 示例、章节测验和 Battle 题巩固。完成本章后，学习者能够把本章工具用于真实但受控的 Linux 场景，并理解常见误操作为什么会发生。

预计学习时间：120 分钟

章节学习目标：
- 理解程序实例与 PID
- 使用 ps 查看进程快照和字段
- 按名称缩小进程查找范围
- 理解 kill 是向进程发送信号
- 理解 &、jobs、fg、bg
- 形成先确认、再终止、再验证的流程
