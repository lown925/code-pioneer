## 课时 1：数据采集与接入

课时简介：学习 数据采集与接入 的核心概念、系统机制和工程边界。

预计学习时间：20 分钟

### 正文

[标题]
数据采集与接入

[文本]
掌握数据接入、质量检查、清洗、转换、加载和幂等处理。 本课围绕“数据采集与接入”建立工程化理解。大数据系统的关键不只是数据量大，还包括分布式存储与计算、数据质量、时效性、容错、资源成本以及可持续运维。

[示例 title=数据采集与接入数据链路]
语言：text
数据源 -> 采集 -> 存储 -> 计算 -> 服务 -> 监控
[/示例]

[提示 title=分析方法]
先明确数据规模、时效要求、访问模式和可靠性目标，再选择存储与计算方案。技术组件应服务于数据需求，而不是为了使用“大数据技术”而使用。

[警告 title=分布式系统边界]
增加节点不会自动解决所有性能问题。网络、数据倾斜、热点、序列化、调度和存储布局都可能成为瓶颈。
