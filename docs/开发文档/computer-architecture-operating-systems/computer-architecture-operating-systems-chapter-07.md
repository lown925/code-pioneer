## 课时 1：操作系统内核与用户态

课时简介：处理器权限级别把应用与内核隔离，敏感操作通常需要通过受控入口进入内核。

预计学习时间：20 分钟

### 正文

[标题]
操作系统内核与用户态：先看系统状态，再看机制

[文本]
处理器权限级别把应用与内核隔离，敏感操作通常需要通过受控入口进入内核。 学习这一课时，重点不是孤立背名词，而是明确“谁保存状态、谁改变状态、变化发生在哪个层次”。这样才能把硬件行为和操作系统抽象联系起来。

[代码 language=python]
# 用伪代码表达本课的状态关系，不依赖具体运行环境
mode = 'kernel' if privileged else 'user'
[/代码]

[标题]
边界与工程判断

[文本]
用户程序不能任意执行所有特权操作。在分析题或真实故障中，应先固定初始条件，再沿数据路径或控制路径逐步推导；不能因为某个部件“通常更快”或“通常这样实现”，就把实现习惯误当成体系结构保证。

[示例 title=操作系统内核与用户态分析示例]
说明：假设系统状态已经给定，先判断当前层次负责什么，再判断下一步状态变化。
语言：text
输入状态 -> 当前机制 -> 状态变化 -> 对上层可见结果
[/示例]

[提示 title=操作系统内核与用户态学习提示]
权限隔离是系统保护的重要基础。做题时把“定义”“机制”“性能影响”分开判断，通常能排除绝对化选项。

[警告 title=不要混淆抽象与具体实现]
课程中的 Python 片段仅用于表达算法或状态转换，不代表底层系统由 Python 实现。不同 CPU、操作系统和文件系统可以采用不同实现，只要满足相应接口与语义。
