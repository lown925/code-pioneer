## 课时 1：CPU 调度目标

课时简介：调度策略需要在响应时间、吞吐量、公平性和资源利用率之间权衡。

预计学习时间：20 分钟

### 正文

[标题]
CPU 调度目标：先看系统状态，再看机制

[文本]

[文本]
