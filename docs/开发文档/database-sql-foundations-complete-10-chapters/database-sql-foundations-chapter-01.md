# 第一章：数据库与 SQL 入门

章节简介：认识关系型数据库、表、行、列以及 SQL 的基本职责，并建立安全执行查询的习惯。 学习完成后，能够把本章 SQL 能力应用到清晰、可验证的数据库查询或设计任务中。

预计学习时间：120 分钟

章节学习目标：
- 理解并能够应用“关系型数据库与表”的核心规则
- 理解并能够应用“认识行、列、主键”的核心规则
- 理解并能够应用“SELECT 基础查询”的核心规则
- 理解并能够应用“WHERE 条件过滤”的核心规则
- 理解并能够应用“ORDER BY 排序”的核心规则
- 理解并能够应用“LIMIT 与结果集控制”的核心规则

## 课时 1：关系型数据库与表

课时简介：学习关系型数据库与表的核心概念、SQL 写法和常见边界。

预计学习时间：20 分钟

### 正文

[标题]
关系型数据库与表的核心思路

[文本]
数据库把同类实体组织为表，表由列定义结构、由行保存记录。SQL 用于定义、查询和维护这些数据。

[代码 language=sql]
SELECT * FROM students;
[/代码]

[标题]
从结果语义理解 SQL

[文本]
学习这一部分时，不要只记住关键字。应先说明查询或约束希望解决什么问题，再检查输入数据范围、结果粒度以及 NULL、重复行和排序等边界。对于“关系型数据库与表”，核心判断是：表用于保存结构一致的记录。

[示例 title=关系型数据库与表示例]
说明：使用一个最小 SQL 示例观察语句结构，不连接或修改生产数据库。
语言：sql
SELECT * FROM students;
[/示例]

[提示 title=关系型数据库与表学习提示]
表中的每一行通常表示一条记录。先预测结果，再阅读 SQL，会比机械背语法更容易形成稳定理解。

[警告 title=注意 SQL 方言与数据边界]
不同数据库在函数、分页、日期处理等细节上可能不同。课程以通用关系型 SQL 思想为主，涉及写操作的示例仅用于学习，不应直接对生产数据库执行。

ORDER BY 排序的核心思路

[文本]

### 正文

[标题]
LIMIT 与结果集控制的核心思路

[文本]
LIMIT 限制返回行数，常与 ORDER BY 配合。只写 LIMIT 而没有确定排序时，不应假设数据库总返回同一批记录。

[代码 language=sql]
SELECT id, name FROM students ORDER BY id LIMIT 10;
[/代码]

[标题]
从结果语义理解 SQL

[文本]
学习这一部分时，不要只记住关键字。应先说明查询或约束希望解决什么问题，再检查输入数据范围、结果粒度以及 NULL、重复行和排序等边界。对于“LIMIT 与结果集控制”，核心判断是：LIMIT 用于限制结果行数。

[示例 title=LIMIT 与结果集控制示例]

语言：sql

[/示例]

[提示 title=LIMIT 与结果集控制学习提示]
稳定取前 N 条通常应配合 ORDER BY。先预测结果，再阅读 SQL，会比机械背语法更容易形成稳定理解。

[警告 title=注意 SQL 方言与数据边界]
