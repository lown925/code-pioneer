章节学习目标：
- 理解并能够应用“数值与字符类型”的核心规则
- 理解并能够应用“日期时间与布尔类型”的核心规则
- 理解并能够应用“NULL 的三值逻辑”的核心规则
- 理解并能够应用“列别名与计算表达式”的核心规则

### 正文

[标题]
数值与字符类型的核心思路

[文本]

[代码 language=sql]

[/代码]

[标题]
从结果语义理解 SQL
