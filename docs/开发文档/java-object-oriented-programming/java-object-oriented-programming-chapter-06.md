## 课时 1：异常体系

课时简介：学习 异常体系 的核心概念、Java 写法与工程边界。

预计学习时间：20 分钟

### 正文

[标题]
异常体系

[文本]
理解异常体系、try-catch-finally、自定义异常以及资源释放。 本课重点不是机械记语法，而是理解 Java 代码背后的对象职责、状态变化和 API 契约。编写代码时要明确数据归属、调用边界和异常情况。

[示例 title=异常体系示例]
语言：java
class Demo {
    public static void main(String[] args) {
        System.out.println("异常体系");
    }
}
[/示例]

[提示 title=学习方法]
先写清楚“对象负责什么”，再决定字段、方法和依赖关系。面向对象不是把所有逻辑都塞进类，而是用清晰职责组织代码。

[警告 title=工程边界]
示例以 Java 17+ 常见语法为主。不同项目版本可能限制语言特性；真实项目还应结合测试、异常处理、资源释放和线程安全要求。
