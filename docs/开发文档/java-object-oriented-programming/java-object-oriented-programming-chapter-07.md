## 课时 1：List 与 ArrayList

课时简介：学习 List 与 ArrayList 的核心概念、Java 写法与工程边界。

### 正文

[标题]
List 与 ArrayList

[文本]

[示例 title=List 与 ArrayList示例]
语言：java
