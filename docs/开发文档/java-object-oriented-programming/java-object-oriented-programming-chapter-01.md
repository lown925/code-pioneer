## 课时 1：Java 平台与 JVM

课时简介：学习 Java 平台与 JVM 的核心概念、Java 写法与工程边界。

预计学习时间：20 分钟

### 正文

[标题]
Java 平台与 JVM

[文本]
建立 Java 程序结构、JVM、类与对象的整体认识。 本课重点不是机械记语法，而是理解 Java 代码背后的对象职责、状态变化和 API 契约。编写代码时要明确数据归属、调用边界和异常情况。

[示例 title=Java 平台与 JVM示例]
语言：java
class Demo {
    public static void main(String[] args) {
        System.out.println("Java 平台与 JVM");
    }
}
[/示例]

[提示 title=学习方法]
先写清楚“对象负责什么”，再决定字段、方法和依赖关系。面向对象不是把所有逻辑都塞进类，而是用清晰职责组织代码。

[警告 title=工程边界]
示例以 Java 17+ 常见语法为主。不同项目版本可能限制语言特性；真实项目还应结合测试、异常处理、资源释放和线程安全要求。

### 课时题目

#### 题目 1

题型：SINGLE_CHOICE

难度：EASY
分值：10
知识点：Java 平台与 JVM
是否用于 Battle：否

选项：
- A. 先明确对象职责与状态，再选择合适的语法和 API [正确]
- B. 所有功能都应该写进一个类
- C. 只要代码能编译，就说明设计一定合理
- D. 所有字段都应该声明为 public

解析：
Java 语法服务于设计。可靠代码需要清晰职责、合理封装和可验证的状态变化。

#### 题目 2

题型：SINGLE_CHOICE
题干：在使用“Java 平台与 JVM”时，哪种做法更利于长期维护？

分值：10

是否用于 Battle：是
Battle 难度：MEDIUM
Battle 展示类型：场景判断

- C. 忽略访问控制，让任何对象都能修改内部状态

#### 题目 3

难度：HARD

知识点：Java 平台与 JVM、重构
是否用于 Battle：是
Battle 难度：HARD
Battle 展示类型：工程判断

- A. 重新划分职责、减少不必要依赖，并通过接口或封装稳定边界 [正确]
- B. 把更多字段改成 public 以方便直接访问
