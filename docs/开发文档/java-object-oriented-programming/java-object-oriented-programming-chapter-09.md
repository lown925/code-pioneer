## 课时 1：函数式接口

课时简介：学习 函数式接口 的核心概念、Java 写法与工程边界。

预计学习时间：20 分钟

### 正文

[标题]
函数式接口

[文本]
掌握函数式接口、Lambda、方法引用和 Stream 基础。 本课重点不是机械记语法，而是理解 Java 代码背后的对象职责、状态变化和 API 契约。编写代码时要明确数据归属、调用边界和异常情况。

[示例 title=函数式接口示例]
语言：java
class Demo {
    public static void main(String[] args) {
        System.out.println("函数式接口");
    }
}
[/示例]

[提示 title=学习方法]
先写清楚“对象负责什么”，再决定字段、方法和依赖关系。面向对象不是把所有逻辑都塞进类，而是用清晰职责组织代码。

示例以 Java 17+ 常见语法为主。不同项目版本可能限制语言特性；真实项目还应结合测试、异常处理、资源释放和线程安全要求。
