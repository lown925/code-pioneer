# 第十二章：文件操作与 JSON

章节简介：学习文件读写、with 语句、文本文件处理，以及 JSON 数据的读取和保存，为后续项目开发打下基础。

## 学习目标

- 理解文件的作用
- 使用 open() 打开文件
- 掌握 r、w、a 模式
- 使用 with 自动关闭文件
- 使用 read()、readline()、readlines()
- 使用 write() 写入文件
- 理解 JSON 数据格式
- 使用 json.load()、json.dump()
- 能完成简单数据持久化

## 课时一：认识文件与 open()

### 正文

文件用于长期保存数据，即使程序关闭，数据仍然存在。

```python
file = open("hello.txt", "r", encoding="utf-8")
content = file.read()
file.close()
```

### 题目

#### 题目1（选择）
Python 中打开文件使用哪个函数？

A. file()
B. open()（正确）
C. read()
D. write()

解析：
open() 用于打开文件。

#### 题目2（填空）

打开文件通常使用 ______ 函数。

答案：
open

解析：
Python 使用 open() 打开文件。

#### 题目3（代码填空）

补全代码读取文件。

```python
file = ____________("hello.txt","r",encoding="utf-8")
```

答案：

```python
open
```

解析：
使用 open() 创建文件对象。

## 课时二：读取文件

## 课时三：写入文件

正文：


## 课时五：JSON 数据

正文：

```python
import json

player = {
    "name":"Tom",
    "rating":1000
}

with open("player.json","w",encoding="utf-8") as file:
    json.dump(player,file,ensure_ascii=False,indent=2)
```

读取：

```python
with open("player.json","r",encoding="utf-8") as file:
    data=json.load(file)
```

题目：
- 选择：JSON 保存什么数据？（结构化数据）
- 填空：读取 JSON 使用 ______。（json.load）
- 代码填空：补全 json.dump(player,file)
