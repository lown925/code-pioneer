# 码站先锋页面与交互说明

文档版本：V1.0
适用版本：码站先锋 V1.0 MVP
文档用途：小程序页面开发、管理后台开发、接口设计、测试验收
前置文档：

* `01-产品需求文档-PRD.md`
* `02-MVP功能范围与验收清单.md`

---

# 1. 文档目的

本文档用于明确码站先锋 V1.0 MVP 中各页面的布局结构、展示内容、按钮行为、页面跳转、登录要求、数据状态和异常处理规则。

本文档主要解决以下问题：

1. 项目需要开发哪些页面。
2. 每个页面展示哪些信息。
3. 页面中有哪些按钮和操作。
4. 点击按钮后进入哪个页面。
5. 哪些操作必须登录。
6. 页面加载、空数据、请求失败时如何展示。
7. 如何防止重复提交和误操作。
8. Codex实现前端时应遵循哪些统一规则。

本文档暂不确定具体视觉稿，不规定精确颜色、字体尺寸和像素距离。

具体视觉样式将在后续 UI 优化阶段确定。

# 2. 产品导航结构

## 2.1 微信小程序底部导航

小程序底部固定设置四个一级入口：

```text
首页
对战
互助
我的
```

对应页面：

```text
首页：pages/home/index
对战：pages/battle/index
互助：pages/community/index
我的：pages/profile/index
```

## 2.2 底部导航规则

1. 底部导航只在四个一级页面显示。
2. 课程详情、章节详情、答题页等二级页面不显示底部导航。
3. 用户切换底部导航时，应保留各一级页面合理的浏览状态。
4. 正在答题或对战时，不允许直接通过底部导航离开。
5. 非答题页面可以正常使用系统返回操作。
6. “我的”页面未登录时显示登录引导，不强制进入登录页。

# 3. 通用页面状态

所有需要访问后端接口的页面，必须考虑以下状态：

```text
INITIAL：初始状态
LOADING：加载中
SUCCESS：加载成功
EMPTY：数据为空
ERROR：加载失败
UNAUTHORIZED：未登录或登录失效
FORBIDDEN：无操作权限
```

---

# 4. 通用加载规则

## 4.1 首次加载

页面首次进入时：

1. 显示加载状态。
2. 禁止用户重复触发相同请求。
3. 请求成功后展示正式内容。
4. 请求失败后展示错误状态。
5. 不允许长时间空白。

## 4.2 下拉刷新

课程列表、帖子列表、错题列表和对战记录支持下拉刷新。

下拉刷新时：

1. 从第一页重新请求数据。
2. 清除已有分页游标。
3. 请求成功后替换原列表。
4. 请求失败时保留原数据。
5. 无论成功或失败，都必须结束刷新动画。

## 4.3 上拉加载

分页列表支持上拉加载更多。

规则：

1. 加载期间不可重复请求下一页。
2. 无更多数据时显示“没有更多了”。
3. 加载失败时显示“加载失败，点击重试”。
4. 新一页数据不得与已有数据重复。
5. 切换筛选条件后，从第一页重新加载。

# 5. 通用错误提示

错误提示分为三种形式。

## 5.1 轻提示

适用于：

* 点赞成功。
* 收藏成功。
* 取消收藏。
* 答案已提交。
* 网络暂时异常。
* 表单字段错误。

形式：

```text
Toast轻提示
```

## 5.2 页面错误状态

适用于：

* 页面主要数据加载失败。
* 内容不存在。
* 内容已下架。
* 无访问权限。

页面应显示：

* 错误图标或占位图。
* 错误说明。
* 重新加载按钮。
* 必要时提供返回按钮。

## 5.3 二次确认弹窗

适用于：

* 退出正在进行的答题。
* 删除帖子。
* 删除评论。
* 退出登录。
* 注销账号。
* 放弃未发布的帖子。
* 后台下架课程。

# 6. 通用登录规则

## 6.1 无需登录的操作

未登录用户可以：

* 查看首页公开内容。
* 查看课程列表。
* 查看已发布课程详情。
* 查看已发布章节内容。
* 查看帖子列表。
* 查看帖子详情。
* 查看用户协议。
* 查看隐私政策。

## 6.2 必须登录的操作

以下操作需要登录：

* 记录学习进度。
* 完成章节。
* 参加章节小测。
* 使用错题本。
* 参加练习。
* 参加人机对战。
* 查看个人对战记录。
* 发布帖子。
* 评论。
* 点赞。
* 收藏。
* 举报。
* 提交意见反馈。
* 查看个人中心数据。

## 6.3 登录拦截

未登录用户点击受保护功能时：

1. 弹出登录提示。
2. 用户选择“立即登录”后进入登录流程。
3. 用户取消后停留在当前页面。
4. 登录成功后返回原页面。
5. 登录成功后可继续执行之前的操作。

不得在用户只是浏览公开内容时强制登录。

# 7. 登录页面

页面路径：

```text
pages/login/index
```

## 7.1 页面目标

帮助用户完成微信账号登录，并说明必要的用户信息和隐私规则。

## 7.2 页面内容

页面包含：

* 产品Logo。
* 产品名称“码站先锋”。
* 产品简短介绍。
* 微信登录按钮。
* 用户协议入口。
* 隐私政策入口。
* 协议勾选框。
* 暂不登录按钮。

## 7.3 按钮行为

### 微信登录

点击后：

1. 检查是否勾选用户协议和隐私政策。
2. 未勾选时提示用户先阅读并同意。
3. 调用微信登录能力获取临时凭证。
4. 将临时凭证提交后端。
5. 登录成功后保存访问令牌。
6. 获取当前用户信息。
7. 返回登录前页面或首页。

### 暂不登录

点击后：

* 返回上一页。
* 无上一页时进入首页。

## 7.4 页面状态

### 登录中

* 登录按钮显示加载状态。
* 禁止重复点击。
* 页面其他登录操作暂时禁用。

### 登录失败

显示：

```text
登录失败，请稍后重试
```

提供重新登录按钮。

## 7.5 验收标准

1. 未勾选协议不能提交登录。
2. 登录过程中不能重复点击。
3. 登录成功后访问令牌正确保存。
4. 登录失败不会错误进入已登录状态。
5. AppSecret不得出现在页面代码中。

```text

```

## 8.1 页面目标

帮助用户快速查看学习状态，并进入课程、练习和人机对战。

* 用户昵称。

## 8.4 当前学习卡片

* 最近学习章节。
* 完成进度。

* “继续学习”按钮。

点击“继续学习”：

* 进入最近学习章节。

包含：

* 人机对战。


第一版显示Python编程入门课程。

每个课程卡片显示：

* 封面。
* 名称。
* 简介。
* 难度。
* 章节数。
* 学习人数。

点击课程卡片进入课程详情。

## 8.7 最近学习区

显示最近学习的最多3个章节。

每项显示：

* 课程名称。
* 章节名称。
* 最近学习时间。
* 完成状态。

无学习记录时隐藏该区域或显示学习引导。

## 8.8 首页状态

### 加载中

显示首页骨架屏或加载占位。

### 请求失败

显示：

```text
首页数据加载失败
```

并提供“重新加载”按钮。

### 未登录

公开课程仍正常显示，个人数据区域显示登录引导。

# 11. 章节详情页面

页面路径：

```text
pages/chapter/detail
```

## 11.1 页面参数

必须接收：

```text
chapterId
```

## 11.2 页面内容

包含：

* 课程名称。
* 章节序号。
* 章节标题。
* 章节简介。
* 预计学习时长。
* 内容块列表。
* 上一章按钮。
* 下一章按钮。
* 完成本节按钮。
* 进入小测按钮。

## 11.3 内容块展示规则

### TEXT

展示普通正文，保留段落和换行。

### HEADING

展示章节内小标题。

### IMAGE

展示图片。

要求：

* 保持合理比例。
* 支持点击预览。
* 加载失败显示占位。
* 不允许图片撑破页面宽度。

### CODE

展示代码块。

要求：

* 使用等宽字体。
* 保留缩进和换行。
* 支持横向滚动。
* 显示编程语言名称。
* 提供复制代码按钮。

### TIP

以提示卡片形式展示。

### WARNING

以警告卡片形式展示。

### EXAMPLE

展示示例标题、说明和示例代码。

### QUESTION

展示内嵌练习。

内嵌练习只提供即时反馈，不计入正式小测成绩。

## 11.4 学习记录规则

用户进入章节后：

1. 已登录用户调用章节开始接口。
2. 记录最近学习章节。
3. 更新最近学习时间。
4. 重复进入不创建重复学习记录。

未登录用户：

* 可以阅读。
* 不记录个人进度。

## 11.5 完成本节按钮

### 无章节小测

点击后：

1. 登录检查。
2. 标记章节完成。
3. 更新课程进度。
4. 提示“本节已完成”。
5. 可进入下一章节。

### 有章节小测

未完成过小测时：

* 点击“完成本节”跳转章节小测。

已完成至少一次小测时：

* 可以直接标记完成。

## 11.6 离开页面

普通阅读状态可直接离开，无需确认。

# 12. 章节小测页面

页面路径：

```text
pages/quiz/index
```

## 12.1 页面参数

必须接收：

```text
chapterId
quizRecordId
```

其中 `quizRecordId` 可以在进入页面前创建，或进入页面后调用开始接口创建。

## 12.2 页面结构

包含：

* 章节名称。
* 当前题号。
* 总题数。
* 题目进度条。
* 题干。
* 代码块。
* 选项。
* 上一题。
* 下一题。
* 提交小测。

## 12.3 答题规则

1. 章节小测不设置单题倒计时。
2. 用户可在提交前修改答案。
3. 用户可返回上一题。
4. 未选择答案的题目标记为未完成。
5. 用户未完成全部题目时不能提交。
6. 正确答案不能在提交前返回前端。
7. 用户提交后不能修改本次答案。

## 12.4 提交按钮

最后一题显示：

```text
提交小测
```

点击后：

1. 检查所有题目是否完成。
2. 如有未完成题目，提示具体题号。
3. 全部完成后弹出确认框。
4. 用户确认后提交。
5. 提交期间禁用所有选项和按钮。
6. 提交成功后进入结果页。
7. 提交失败后保留用户答案。

## 12.5 离开确认

用户在未提交时返回：

```text
当前小测尚未提交，确定离开吗？
```

用户确认离开后：

* 保留或放弃当前记录由后端状态决定。
* 第一版建议保留未完成记录，但再次进入时可重新开始。

1. 调用退出接口。
2. 对战状态改为中途退出。
3. 扣除对应积分。
4. 返回对战首页。

## 19.8 系统异常

* 不扣除用户积分。
* 页面显示异常说明。
